FIELD NOTE 10 · KINETIRX

An AI SDK Is Still Production Software With Supply-Chain Risk

CERT-In warned on 23 October 2026 of a LiteLLM package and container compromise. Microsoft’s analysis described malicious Python startup files in the affected release.

By Raktim Ranjit · 27 October 2026 · 5 min read

The incident, and the question it raises

AI features inherit the security posture of their package managers, build pipeline, environment, and API credentials. A sensible review asks which versions are installed, what secrets the process can read, what happens if an optional provider is unavailable, and who reviews the output.

Where KinetiRx fits

KinetiRx documents Gemini as an optional integration for purchase-bill OCR and a clinical assistant; without the API key, the core application has an offline fallback. Keeping AI optional gives the operator a way to disable that path while continuing ordinary pharmacy workflows.

A clear boundary

Optional AI is not a security guarantee. Protect API keys, patch promptly, verify software versions, and require human review of extracted medicine purchase data and clinical content.
